# Tea Cozy - Codecademy HTML & CSS Project

In this project, I created a fictional tea shop website on my own computer, using the Visual Studio Code tool and keeping track of versions with CLI and Git.
Codecademy had the design specifications and the images required to complete the project.

## Tools used

* VSC
* CLI
* Git
* HTML
* CSS

## Project visualization

You can have a look of the final project in the following link: [Tea Cozy](https://tea-cozy-psi.vercel.app/)
